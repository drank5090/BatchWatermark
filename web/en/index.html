Core Features

  • ✨ Creative Mode (Art Library + Smart Auto-Layout + Free Drag)

    Upload transparent PNG stickers and multi-line text into your Watermark Library. Auto-generate varied-size artistic compositions that protect faces/subjects, then drag, resize, rotate, lock, or sync across all images.

  • Bulk Image & Video Watermarking

    Import dozens of photos, videos, or entire folders via picker or drag-and-drop. Auto-corrects mobile EXIF orientation and preserves original audio on video export.

  • Multi-Line Text & Transparent Logo Watermarks

    Load custom local .ttf / .otf / .woff2 fonts, adjust stroke, drop shadow, line height, opacity, and angle, or scale transparent PNG/WebP logos proportionally.

  • Anti-Theft Tiling & 3×3 Anchor Grid

    Brick-staggered diagonal tiling resists cropping; single-anchor mode provides a 3×3 grid with percentage margins and fine X/Y offsets.

  • Real-Time Multi-Preview (Desktop & Mobile)

    Every parameter tweak updates all previews simultaneously. Mobile view pins the live preview/canvas above thumb-friendly tabs.

  • Orientation Split & Portable JSON Packs

    Separate landscape and portrait sets automatically, export into organized subfolders, and share JSON presets/libraries seamlessly with the Desktop EXE.

4 Simple Steps to Watermark Locally

  1. Choose Work Mode or Creative Mode：Use the top tabs to switch between Work Mode (fast batch image/video watermarking, tiling, 3x3 anchors, orientation split) and Creative Mode (sticker + text library, smart subject-avoiding varied-size layouts, free drag/resize/rotate).
  2. Import Images, Videos, or Watermark Assets：Select files, import an entire folder, or drag & drop directly. In Creative Mode, upload transparent PNG/WebP stickers and custom multi-line text into your persistent Watermark Library.
  3. Live Preview & Fine-Tune：Work Mode refreshes every thumbnail and video frame in real time. Creative Mode generates balanced varied-size art layouts in one click and lets you drag, resize, rotate, or lock any individual watermark.
  4. Export Locally in One Click：Download single files directly, export a UTF-8 ZIP bundle, or write straight into a local folder on Chrome/Edge — 100% private in browser memory.

Frequently Asked Questions (FAQ)

Is BatchWatermark free? Do I need an account?

Yes — 100% free and MIT open-source with no login, no file count limits, and no forced branding watermarks.

Are my photos or videos uploaded to any server?

Never. Image decoding, Canvas 2D compositing, Creative Mode saliency analysis, MediaRecorder video encoding, and ZIP creation all run strictly inside your local browser memory.

What is the difference between Work Mode and Creative Mode?

Work Mode is built for high-speed batch watermarking of photos and videos (tiled or anchored, with landscape/portrait isolation). Creative Mode is tailored for illustrators, photographers, and creators: upload sticker & text libraries, auto-generate varied-size art watermarks that avoid faces/subjects, and drag/resize/rotate individual layers freely.

Does it work on mobile phones (iOS & Android)?

Yes. Both Work Mode and Creative Mode adapt cleanly to mobile screens with a pinned live preview/canvas on top, touch-friendly category tabs below, and direct single-file downloads.

Which image and video formats are supported?

Images: JPG, JPEG, PNG, WebP, BMP, GIF, and AVIF (export as original, JPEG, PNG, or WebP with quality control). Videos: MP4, WebM, and MOV exported locally with original audio preserved.

Can I apply different watermarks to landscape and portrait photos?

Yes. Toggle 'Split Orientation' in Work Mode to separate landscape (W >= H) and portrait (H > W) items, optionally configure independent watermark settings, and auto-export into separate subfolders.

Are watermark libraries and presets compatible with the Desktop EXE?

Yes. Both Work Mode presets and Creative Mode Watermark Library packs export as portable UTF-8 JSON files that work identically between Web and the Windows Desktop EXE.

Is there an offline desktop app for large or long HD videos?

Yes. Download the standalone Windows single-file EXE (Python + PySide6 + bundled FFmpeg) from GitHub Releases for faster H.264 MP4 video encoding and offline batch processing.
