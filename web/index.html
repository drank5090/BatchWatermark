BatchWatermark：在线批量给图片和视频加水印

BatchWatermark 网页版是一款完全运行在浏览器本地的批量加水印工具。一次导入几十上百张照片、商品图或短视频， 调整文字水印或 Logo 水印参数时，所有预览会同步实时刷新；确认效果后可一键打包导出 ZIP，或直接写入本地文件夹。 所有文件只在你的设备内存中处理，绝不上传服务器，适合摄影作品、电商图片、自媒体素材与内部资料的版权保护。

核心功能

  • 批量图片与视频加水印

    支持 JPG、PNG、WebP、BMP、GIF 图片与 MP4、WebM、MOV 视频，可多选文件、导入整个文件夹或直接拖拽，一次处理整批素材。

  • 文字水印与 Logo 水印

    多行文字、常用中英文字体与自定义字体文件，可调颜色、描边、阴影和行间距；也可使用带透明背景的 PNG / WebP Logo 按比例缩放。

  • 全图平铺防盗与九宫格定位

    平铺模式可调水平/垂直间距、旋转角度与砖墙交错排布；单点模式支持九宫格锚点、边距百分比与精细位置微调。

  • 多图实时同步预览

    基于 HTML5 Canvas 实时渲染，修改任一参数即可看到全部图片与视频帧的水印效果，支持高清大图与视频时间轴预览，所见即所得。

  • 横版与竖版分开处理

    开启「横竖隔离」后横版与竖版分组展示，可为 16:9 横屏和 9:16 竖屏分别设置水印，导出时自动分到「横版/」「竖版/」文件夹。

  • 水印预设保存与导入导出

    常用水印样式一键保存在浏览器本机，支持 JSON 文件导入导出，与 BatchWatermark 桌面端 EXE 的预设完全互通。

如何在线批量加水印？只需 4 步

  1. 导入素材：点击「添加图片/视频」或「添加文件夹」，也可以把文件直接拖到左侧预览区。
  2. 设置水印：在右侧面板选择文字水印或图片 Logo，调整字体、字号、颜色、不透明度与旋转角度。
  3. 选择排布：使用「全图平铺」防止盗图，或用「单点定位」把水印放在右下角等九宫格位置。
  4. 批量导出：设置文件名前缀/后缀与输出格式，点击「打包导出 ZIP」或「直接导出到本地文件夹」。

常见问题

BatchWatermark 在线加水印免费吗？需要注册吗？

完全免费并基于 MIT 协议开源，无需注册登录、不限使用次数，打开网页即可使用。

我的图片和视频会被上传到服务器吗？

不会。图片解码、水印绘制、视频录制与 ZIP 打包全部在浏览器本地完成，网页没有任何上传接口，可放心处理私密或商业素材。

支持哪些图片和视频格式？可以导出什么格式？

图片支持 JPG / PNG / WebP / BMP / GIF，可保持原格式或导出为 JPEG、PNG、WebP 并调节质量；视频支持 MP4 / WebM / MOV，通过浏览器原生 MediaRecorder 导出 MP4 或 WebM，并可保留原声。

如何给图片加平铺水印防止盗图？

在「位置与排布」中选择「全图平铺」，设置 -25° 或 -45° 的旋转角度、合适的不透明度与间距，并勾选「奇偶行交错排布」，即可得到覆盖整张图片、难以裁剪去除的防盗水印。

横版和竖版图片可以使用不同的水印吗？

可以。点击顶部「横竖隔离」，勾选「横版与竖版使用独立水印参数」，即可分别编辑两种方向的水印，导出时自动保存到「横版/」与「竖版/」子文件夹。

需要处理大量视频，有桌面版吗？

有。BatchWatermark 提供基于 Python、PySide6 与 FFmpeg 的 Windows 桌面端，导出 H.264 MP4 更快、兼容性更好，可在 GitHub Releases 免费下载 EXE，预设 JSON 与网页版互通。
