BatchWatermark：在线批量给图片和视频加水印

BatchWatermark（主站 watermark.zak-cloud.top）是一款完全运行在浏览器本地的免费批量图片与视频加水印工具。 一次导入几十上百张照片、电商商品图、证件扫描件或短视频，在调整文字水印或透明 Logo 水印参数时，所有预览会同步实时刷新； 确认效果后可单图直下、一键打包导出 ZIP，或在 Chrome / Edge 中直接写入本地文件夹。 所有编解码与渲染均在你的设备内存中完成，零服务器上传，彻底杜绝隐私与商密泄露风险。

核心功能

  • ✨ 创作模式（图文水印库 + 智能避让 + 自由拖拽）

    支持顶部标签页在「工作模式」与「创作模式」间独立切换；可上传透明贴纸与多条文字组建水印库，一键生成避让人物主体的大小错落艺术水印，也支持直接拖拽、缩放、旋转单个水印并按比例同步套用到多张图。

  • 批量图片与视频加水印

    支持多选文件、导入整个文件夹或直接拖拽整批素材；自动校正手机照片 EXIF 拍摄方向，视频导出可保留原声。

  • 多行文字水印与 Logo 水印

    支持常用中英文字体与本地导入 .ttf / .otf / .woff2 自定义字体，可调颜色、描边、阴影与行间距；透明 PNG / WebP Logo 按宽度比例缩放。

  • 全图平铺防盗与九宫格定位

    平铺模式可调水平/垂直间距、-180°~180° 旋转角度与奇偶行砖墙交错；单点模式提供 3×3 九宫格定位、边距百分比与精细偏移。

  • 多图实时同步预览（PC + 手机适配）

    修改任一参数即可同时看到全部图片与视频帧的水印变化；手机端采用固定实时预览 + 底部触控标签切换，单手操作流畅。

  • 横版与竖版一键隔离处理

    开启「横竖隔离」后横版与竖版分区展示，可为 16:9 横屏和 9:16 竖屏分别定制不同水印，导出自动分目录保存。

  • 自定义预设保存与 JSON 导入导出

    常用品牌或防盗水印样式一键保存到本机，支持单个或全部预设导出 JSON，团队协作或更换设备一键复用。

如何在线批量加水印？只需 4 步

  1. 导入素材：点击「添加图片/视频」或「添加文件夹」，也可以把文件直接拖拽到预览区。
  2. 设置水印：选择文字水印或图片 Logo，调整字体、字号、颜色、描边、不透明度与旋转角度。
  3. 选择排布：使用「全图平铺」防止盗图，或用「单点定位」把水印放在九宫格指定角落；混合横竖素材可一键开启「横竖隔离」。
  4. 批量导出：设置文件名前缀/后缀与输出格式，单图可直接下载，多图一键「打包导出 ZIP」或直接写入本地文件夹。

常见问题（FAQ）

BatchWatermark 在线加水印免费吗？需要注册登录吗？

完全免费并基于 MIT 协议开源，无需注册登录、无张数限制、无强制品牌角标，打开 watermark.zak-cloud.top 或 GitHub Pages 镜像即可直接使用。

我的图片和视频会被上传到服务器吗？

绝不会上传。图片解码、Canvas 水印绘制、MediaRecorder 视频合成与 ZIP 打包全部在您的浏览器本地内存中完成，没有任何文件上传接口，适合处理商业素材、证件照与内部文档。

支持手机端使用吗？

支持。网页版针对 iOS Safari 与 Android 浏览器做了专属移动端布局优化：顶部固定实时预览区，下方通过分类标签切换文字、样式、排布、预设与导出设置，单图支持直接下载保存到手机。

支持哪些图片和视频格式？可以导出什么格式？

图片支持 JPG / JPEG / PNG / WebP / BMP / GIF / AVIF，可保持原格式或转换为 JPEG、PNG、WebP 并调节质量；视频支持 MP4 / WebM / MOV，通过浏览器本地 MediaRecorder 导出 MP4 或 WebM 并保留原声。

如何给图片加斜向平铺水印防止盗图？

在「位置与排布」中选择「全图平铺」，将旋转角度设为 -25° 或 -45°，调节不透明度与水平/垂直间距，并勾选「奇偶行交错排布（砖墙错位）」，即可生成覆盖整张图片、难以裁剪去除的防盗水印。

横版和竖版图片可以使用不同的水印并分开导出吗？

可以。点击顶部「横竖隔离」，预览区会自动分为「横版媒体区（宽 ≥ 高）」和「竖版媒体区（高 > 宽）」；勾选「横版与竖版使用独立水印参数」即可分别调节，导出时自动归入「横版/」和「竖版/」子文件夹。

watermark.zak-cloud.top 和 GitHub Pages 地址有什么区别？

两个地址部署的是同一套开源代码，功能完全一致。watermark.zak-cloud.top 是官方推荐主站（访问更稳定且支持根路径完整 SEO/PWA 特性），drank5090.github.io/BatchWatermark/ 是官方 GitHub Pages 镜像。

需要处理大量高清长视频，有离线桌面版吗？

有。BatchWatermark 提供基于 Python、PySide6 与内置 FFmpeg 7.1 的 Windows 独立单文件 EXE，导出 H.264 MP4 速度更快、格式兼容更广，可在 GitHub Releases 免费下载，且预设 JSON 与网页版 100% 互通。
