BatchWatermark：画像・動画の一括透かし＆イラスト向けアート透かし作成

BatchWatermark（公式サイト watermark.zak-cloud.top）はブラウザ内で完結する無料の画像・動画一括透かしツールです。サーバーへのファイル送信は一切ゼロ。高速な一括処理のワークモードと、透過スタンプ＆文字を人物回避しながら大小ランダム配置できるクリエイティブモードを上部タブで自在に切り替えられます。

主要機能

  • ✨ クリエイティブモード（イラスト・作品向けアート透かし）

    透過 PNG スタンプと複数行テキストをライブラリ登録。顔や主体を回避しつつ大小メリハリのあるアート透かしを自動生成し、個別の移動・拡縮・回転・ロックや全画像への一括適用ができます。

  • 画像・動画の一括透かし処理

    複数ファイルやフォルダ丸ごとのドラッグ＆ドロップに対応。スマホ写真の EXIF 向きを自動補正し、動画は元の音声を保ったまま書き出せます。

  • 多行テキスト＆透過ロゴ透かし

    ローカルの .ttf / .otf / .woff2 フォント読み込み、縁取り、影、行間、透明度・角度調整に対応。透過 PNG / WebP ロゴも比率維持で配置可能。

  • 盗用防止タイル＆9点アンカー配置

    レンガ状に互い違い配置する斜め全面タイルで切り抜きを防止。単点配置では 3×3 アンカーと余白・オフセット微調整に対応。

  • 複数同時プレビュー（PC・スマホ最適化）

    パラメータ変更が全プレビューへ即座に反映。スマホではキャンバス固定＋下部タブ操作で片手でも快適です。

  • 縦横分離＆JSON プリセット共有

    横長・縦長を分けて設定・書き出し可能。プリセットと透かし素材庫は JSON でデスクトップ版と自在にやり取りできます。

4ステップで完了する使い方

  1. ワークモードまたはクリエイティブモードを選択：上部タブで「ワークモード」（画像・動画の一括タイル／9点配置・縦横分離）と「クリエイティブモード」（透過スタンプ＆文字ライブラリ・人物回避自動配置・自由ドラッグ）を切り替えます。
  2. 画像・動画または透かし素材を読み込む：ファイル複数選択、フォルダ読み込み、ドラッグ＆ドロップに対応。クリエイティブモードでは独自の透過PNGスタンプや複数行テキストをライブラリに保存できます。
  3. リアルタイムプレビューと微調整：ワークモードは全サムネイルと動画フレームを同時更新。クリエイティブモードは「自動レイアウト／別の案」で一括生成し、個別の移動・拡縮・回転・ロックも可能です。
  4. ワンクリックでローカル書き出し：単体ダウンロード、UTF-8 ZIP 一括保存、または Chrome / Edge でのローカルフォルダ直接書き出しに対応。データは外部へ送信されません。

おすすめの活用シーン

  • イラスト・同人・コミッションの盗用防止

    クリエイティブモードで雪の結晶・スタンプ・詩的な署名テキストを人物の顔を避けて美しく自動配置し、無断転載やAI学習対策に活用できます。

  • EC 商品画像・写真納品の一括処理

    ワークモードで数十〜数百枚の商品写真やサンプル画像を同時プレビューし、横向き・縦向き別フォルダで一気に納品準備。

  • 本人確認書類・社内資料の保護

    「提出専用・複製禁止」などの斜め透かしを完全ローカルで追加。機密画像が外部ネットワークに出ることはありません。

よくある質問（FAQ）

BatchWatermark は無料ですか？アカウント登録は必要ですか？

完全無料・MIT ライセンスのオープンソースです。登録やログインは不要で、処理枚数の上限や強制ロゴもありません。

画像や動画がサーバーにアップロードされることはありますか？

一切ありません。画像デコード、Canvas 2D 合成、主体回避解析、動画録画、ZIP 生成まですべてお使いのブラウザ内メモリで完結します。

ワークモードとクリエイティブモードの違いは何ですか？

ワークモードは大量の写真・動画に斜めタイルやロゴ透かしを素早く一括適用する用途向けです。クリエイティブモードはイラスト・同人作品・写真向けに、複数の透過PNGスタンプや文字を人物の顔を避けつつ大小バランスよく自動配置し、そのまま自由ドラッグで微調整できます。

スマートフォン（iPhone / Android）でも使えますか？

はい。スマホ画面ではプレビュー・編集キャンバスを上部に固定し、下部タブで直感的にパラメータや素材ライブラリを切り替えられ、1枚だけの直接保存にも対応しています。

対応している画像・動画フォーマットは？

画像は JPG / JPEG / PNG / WebP / BMP / GIF / AVIF に対応し、元形式維持または JPEG / PNG / WebP 書き出しが可能。動画は MP4 / WebM / MOV に対応し、音声を保持してローカル書き出しできます。

横向き画像と縦向き画像で別々の透かし設定・別フォルダ書き出しはできますか？

はい。ワークモード上部の「縦横分離」をオンにすると横向き（幅 ≥ 高さ）と縦向き（高さ > 幅）を自動分類し、個別設定と別サブフォルダ出力が行えます。

作成した透かしライブラリやプリセットはデスクトップ版と共有できますか？

はい。ブラウザ内（IndexedDB / localStorage）に自動保存されるほか、UTF-8 JSON パックとして書き出し、Windows デスクトップ EXE 版と双方向に読み込めます。

長時間の高画質動画を大量処理したい場合、オフライン版はありますか？

はい。Python + PySide6 + FFmpeg 内蔵の Windows 単体実行 EXE 版を GitHub Releases で無料配布しており、ワーク＆クリエイティブ両モードと4言語切替に対応しています。
