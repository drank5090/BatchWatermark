BatchWatermark：線上批次圖片與影片加浮水印 & 藝術創作工作室

BatchWatermark（主站 watermark.zak-cloud.top）是一款完全運行於瀏覽器本機的免費批次圖片與影片加浮水印工具，全程零伺服器上傳。可於頂部分頁自由切換工作模式（高效批次圖片/影片）與創作模式（圖文浮水印庫、智慧避讓主體多尺度藝術排版與自由拖曳精修）。

核心功能

  • ✨ 創作模式（圖文浮水印庫 + 智慧避讓 + 自由拖曳）

    上傳透明 PNG 貼紙與多行文字組成浮水印庫，一鍵產生避讓人物主體的大小錯落藝術浮水印，並可單獨拖曳、縮放、旋轉、鎖定或按比例套用至全部圖片。

  • 批次圖片與影片加浮水印

    支援多選檔案、匯入整個資料夾或直接拖曳整批素材；自動校正手機照片 EXIF 方向，影片匯出可保留原聲。

  • 多行文字與透明 Logo 浮水印

    支援常用中英文字體與載入本機 .ttf / .otf / .woff2 自訂字體，可調顏色、描邊、陰影與行距；透明 PNG / WebP Logo 依寬度比例縮放。

  • 全圖平鋪防盜與九宮格定位

    平鋪模式可調水平/垂直間距、-180°~180° 旋轉角度與磚牆交錯；單點模式提供 3×3 九宮格定位與精細偏移。

  • 多圖即時同步預覽（桌機 + 手機適配）

    調整任一參數即可同步看到所有圖片與影片幀的浮水印變化；手機端採頂部固定畫布 + 分類分頁設計，單手流暢操作。

  • 橫豎隔離與跨端 JSON 互通

    自動區分橫版與直版媒體分別調參與匯出；預設與創作浮水印庫 JSON 與桌面端 EXE 100% 互通。

4 步驟完成本機批次加浮水印

  1. 選擇工作模式或創作模式：在頂部分頁切換「工作模式」（高效批次圖片/影片、平鋪/九宮格、橫豎隔離）或「創作模式」（圖文浮水印庫、自動避讓主體多尺度藝術排版、自由拖曳）。
  2. 匯入圖片、影片或浮水印素材：支援多選檔案、匯入整個資料夾或直接拖曳進入畫布；創作模式還可上傳透明 PNG 貼紙與多行文字建立本機持久化浮水印庫。
  3. 即時預覽與精細微調：工作模式所有圖片與影片幀同步即時刷新；創作模式可一鍵「智慧排版 / 換一版」，並直接拖曳、縮放、旋轉或鎖定任意單一浮水印。
  4. 一鍵本機高畫質匯出：支援單檔直接下載、零依賴 UTF-8 ZIP 批次打包匯出，或在 Chrome/Edge 直接寫入本機資料夾，全程零伺服器上傳。

常見應用場景

  • 插畫、約稿與原創作品防盜

    使用創作模式將雪花、印章與落款文字自動避開人物臉部並大小錯落排布，兼顧防盜與畫面美感。

  • 電商商品圖與攝影交件樣圖

    於工作模式一次匯入數十張商品照或攝影毛片，同步預覽並依橫版/直版自動分資料夾匯出。

  • 證件掃描件與內部機密文件

    在瀏覽器本機加上「僅供審核使用」斜向平鋪防盜字樣，檔案全程不離開您的裝置。

常見問題（FAQ）

BatchWatermark 線上加浮水印免費嗎？需要註冊登入嗎？

完全免費並採用 MIT 授權開源，無需註冊登入、無張數限制、無強制品牌角標，開啟 watermark.zak-cloud.top 或 GitHub Pages 鏡像即可直接使用。

我的圖片與影片會被上傳到伺服器嗎？

絕不會上傳。圖片解碼、Canvas 浮水印繪製、創作模式顯著度分析、MediaRecorder 影片合成與 ZIP 打包全部在您的瀏覽器本機記憶體內完成，沒有任何檔案上傳介面。

工作模式與創作模式有什麼差別？

工作模式專注於高效批次為圖片與影片加上文字/Logo 平鋪或九宮格浮水印，並支援橫豎隔離匯出；創作模式專為插畫、攝影與委託稿防盜打造，支援上傳圖文浮水印庫、演算法自動避讓主體產生大小不一的藝術排版，且每個元素皆可自由拖曳精修。

支援手機端使用嗎？

支援。網頁版針對 iOS Safari 與 Android 瀏覽器做了專屬行動端介面優化：頂部固定即時預覽/互動畫布，下方透過分類分頁切換參數，單圖可直接下載儲存到手機。

支援哪些圖片與影片格式？可匯出什麼格式？

圖片支援 JPG / JPEG / PNG / WebP / BMP / GIF / AVIF，可保留原格式或轉換為 JPEG、PNG、WebP 並調整品質；影片支援 MP4 / WebM / MOV，於瀏覽器本機匯出 MP4 或 WebM 並保留原聲。

橫版與直版圖片可以使用不同的浮水印並分開匯出嗎？

可以。在工作模式點擊頂部「橫豎隔離」，預覽區會自動分為橫版區（寬 ≥ 高）與直版區（高 > 寬），支援獨立參數設定，匯出時自動分類至對應子資料夾。

創作模式的浮水印庫能與桌面版互通嗎？

可以。創作模式浮水印庫自動儲存於瀏覽器本機 IndexedDB，並支援匯出標準 UTF-8 JSON 檔案包，與 Windows 桌面 EXE 版 100% 雙向匯入匯出互通。

需要處理大量高畫質長影片，有離線桌面版嗎？

有。BatchWatermark 提供基於 Python、PySide6 與內建 FFmpeg 的 Windows 獨立單檔 EXE，同樣內建工作模式與創作模式及四語言切換，可於 GitHub Releases 免費下載。
